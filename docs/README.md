## 1. 关键决策（一眼看全）

- **风格**：卡通治愈 + 夸张搞怪；HUD 浮层贴边、可收起、不挡 3D 厨房。
- **渲染**：Three.js（r160+），命令式，不套 React 管 3D。
- **物理**：cannon-es 起步（否决已停更的 Cannon.js）；刚体 >200 迁 Rapier。
- **工程**：Vite + TypeScript；存档 IndexedDB；资源 glTF+Draco+KTX2。
- **性能门槛**：60FPS / 16.6ms；Draw call≤200、三角面≤50 万、显存≤256MB、首屏≤3s。

## 2. 核心循环

`采购 → 烹饪(物理+QTE) → 定价售卖 → 升级/随机事件 → 打烊结算 → 次日`（闭环滚动）
