# 3D 烹饪经营游戏 · UI 概念设计

> 角色：UI 设计师 ｜ 阶段：顶层概念设计（不写代码）
> 风格锚点：**卡通治愈 + 夸张搞怪**（圆润、暖色、食欲感；反馈要浮夸、有梗、有戏）

---

## 1. 设计定位

游戏基调是"极易上手、极难精通、极其杀时间"。UI 必须做到三点：

- **一眼就懂**：火候、订单、耐心值不靠说明书，靠形状和颜色说话。
- **反馈拉满**：每一次成功颠勺、每一枚金币、每一次顾客暴走，都要有夸张的视觉和动效。
- **不挡画面**：HUD 是浮层，3D 厨房是主角。所有控件贴边、半透明、可收起。

## 2. 视觉语言

### 2.1 色板

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 背景奶油 | `#FFF6E5` | 治愈底色，降低长时间游玩疲劳 |
| 主色暖橙 | `#FF9F45` | 食欲色，主按钮、火候高光 |
| 治愈薄荷 | `#6FCF97` | 成功、耐心充足、好评 |
| 警示红 | `#FF5E5E` | 焦糊、耐心告急、差评 |
| 文字深棕 | `#4A3528` | 比纯黑柔和，配奶油底 |
| 高光奶黄 | `#FFE08A` | 甜点区发光、连击数字 |

### 2.2 形状与字体

- 形状：大圆角（12–20px）、微胖胶囊、水滴与火焰拟物。
- 字体：圆体无衬线（如 `Baloo 2` / `ZCOOL KuaiLe` 中文圆体），数字用等宽圆体保证跳动时不抖。
- 描边：组件用 2px 深棕描边，做出"贴纸贴上去"的卡通质感。

### 2.3 动效基调

- 弹性（spring/ease-out-back）为主，点击有回弹。
- 成功用"弹 + 发光 + 粒子"三段式；失败用"抖 + 裂 + 灰"。
- 全程禁用 CSS 重排动画，只用 `transform` / `opacity`。

- 战斗时（高峰期）HUD 自动进入"紧凑模式"：订单栏收窄、非关键信息淡出。

## 4. 三大核心 HUD 组件

### 4.1 火候条（Heat Bar）

**干什么**：实时显示当前锅具火候，并标出本道菜要求的"甜点区"，配合 QTE 决定品质。

**形态**：横向"火焰温度计"。
- 左端蓝（生）→ 中段金（刚好）→ 右端黑红（糊），颜色随数值连续渐变。
- **甜点区**用发光高亮带，宽度随菜品要求的火候区间变化（煎蛋窄、炖汤宽）。
- 条下方叠一层**焦痕进度**（黑色），超过阈值菜品外观变焦黑。

**QTE 机制**：
- 甜点区两侧有脉冲光圈，光圈向内收缩。
- 光圈收缩进入甜点区瞬间点击 → 完美（品质 +30%）。
- 早/晚点击进入相邻区 → 普通/夹生/微糊。
- 完全错过 → 焦糊，焦痕进度猛涨。

**数值规格**：火候 0–100；典型甜点区 70–85；焦糊阈值 92。

### 4.2 订单栏（Order Tray）

**干什么**：展示排队顾客要的菜、特殊要求、剩余时间。

**形态**：左侧上滑的"票据栈"。
- 每张订单卡：顾客头像 emoji + 菜名 + 要求标签（🌶️辣 / 🍬少糖 / ⚡快）+ 环形倒计时。
- 环形倒计时变色：绿 → 黄 → 红；归零时卡片**碎裂飞走**并冒黑烟。
- 多订单时卡片轻微错落堆叠，最新订单从顶部弹入。
- 点击卡片 → 镜头聚焦对应顾客，高亮其需求。

**容量**：同屏最多显示 6 张，超出折叠为"+N"。

### 4.3 顾客耐心值（Patience Bubble）

**干什么**：用表情替代进度条，传达情绪比数字更直观、更有戏。

**形态**：顾客头顶气泡，内含"表情脸 + 环形进度"。
- 表情五段：😊（满）→ 🙂 → 😟 → 😣 → 🤬（归零）。
- 气泡底色随耐心 drained：绿 → 黄 → 橙 → 红。
- 归零时顾客**摔叉子 / 头顶冒黑气**，离场并掉声誉。

**联动**：耐心低于 25% 时气泡开始抖动 + 红色脉冲，给玩家最后抢救信号。

## 5. 关键反馈（Juice）

| 事件 | 反馈 |
| --- | --- |
| 连击上菜 | 屏幕中央弹 `连击 xN 🔥`，数字越大字越炸，N≥10 触发全屏金色闪光 |
| 金币入账 | 金币从顾客飞向顶栏，数字弹性跳动 + "叮"音 |
| 极品美食 | 顾客眼睛变 ⭐、原地转圈、头顶冒爱心粒子 |
| 焦糊 | 画面边缘焦黑晕影 + 锅具冒黑烟 + 低沉"噗"音 |
| 顾客暴走 | 叉子飞出 + 黑气 + 屏幕轻微震一下 |
